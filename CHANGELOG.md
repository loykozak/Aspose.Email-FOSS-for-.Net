# Changelog

All notable changes to this package will be documented in this file.

## [0.1.0] - 2026-03-18

### Added

- Initial C# package scaffold.
- KB-driven metadata generation for foundational CFB and MSG constants and enums.
- Dependency-free CFB reader and writer surface.
- MSG document reader and writer surface.
- High-level `MapiMessage` model with recipients, attachments, and embedded-message attachments.
- Repository-owned MIME reader and writer powering `LoadFromEml` and `SaveToEml`.
